## 🎯 Propósitos

1. Tener una forma rápida y sencilla de subir proyectos universitarios.
2. Funcionar como respaldo en caso de perder los archivos de manera local.
3. Compartir y sincronizar los proyectos con otros dispositivos, integrantes de equipo y profesores
4. Que el docente pueda analizar y evaluar el codigo de manera sencilla sin necesidad de descargarlo en su equipo.


---

## 📂 Organización de los proyectos

El repositorio se dividirá en **carpetas y subcarpetas**.

Existirá una carpeta por unidad. Cada carpeta llevará el nombre de la unidad en Moodle y cada unidad tendrá subcarpetas, cada una perteneciendo a los diferentes trabajos que se realicen por unidad.

### 📌 Proyecto final

Además de las carpetas individuales por unidad, habrá una carpeta extra dedicada al **proyecto final**.

Esta se irá actualizando independientemente a lo largo del semestre según los avances que se le realicen al mismo.

## 🗂️ Ejemplo de estructura en uso

Como se mencionó, cada proyecto o trabajo tendrá su carpeta dentro de la unidad que le corresponda y tendrá las carpetas que sean necesarias dentro de él.

Por lo que un ejemplo para el funcionamiento del mismo es el siguiente:

```text
📦 Repositorio
│
├── 📂 HTML
│   └── 📂 Trabajo uno
│       ├── 📂 CSS
│       ├── 📂 HTML
│       ├── 📂 JAVASCRIPT
│       └── 📂 RECURSOS
│
├── 📂 CSS
│
├── 📂 JAVASCRIPT
│
├── 📂 SERVIDORES
│
├── 📂 PROGRAMACION DEL LADO DEL SERVIDOR
│
└── 📂 PROYECTO FINAL
```
